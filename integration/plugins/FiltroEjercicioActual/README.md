# FiltroEjercicioActual

Al abrir un listado de **presupuestos, pedidos, albaranes, facturas o recibos**, tanto de ventas como de compras, muestra automáticamente los documentos cuya fecha pertenece al año en curso cuando el listado tiene fecha. Cada usuario también puede guardar sus filtros nativos de FacturaScripts y establecer uno como predeterminado.

## Uso

- El botón **Guardar** de FacturaScripts permite dar un nombre a los filtros actuales y recuperarlos después.
- Junto a cada filtro guardado aparece una **estrella**. Púlsala para usarlo automáticamente al entrar en ese listado; vuelve a pulsarla para quitarlo.
- Cada predeterminado pertenece solo al usuario que lo ha creado y al listado concreto.
- Los predeterminados se guardan en una tabla propia del plugin. Por ello cambiar el nombre, la descripción o el orden de los filtros guardados no altera cuál está marcado como predeterminado.

## Instalación

1. En FacturaScripts, abre **Administrador > Plugins**.
2. Pulsa **Añadir** y selecciona el archivo ZIP.
3. Activa el plugin.
4. Pulsa **Reconstruir** si FacturaScripts lo solicita.
